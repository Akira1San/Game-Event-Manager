# Plan: Test 2 Scene — Rotating Objects, WSAD Player, Platform, Cylinder Grab

## Goal

Create `Content/scenes/test_2.scene` plus matching `.events` files demonstrating:
- Rotating cube + rotating sphere (always rotate, toggled off/on with T / R keys)
- Player cube moving with W/A/S/D

## Notes / risks

- All static models use the Floor cube model GUID since sphere/cylinder/cone model GUIDs aren't available in the project yet. Visuals will all be cubes; replace models in the Flax editor after scene creation.
- `turn left degrees 2` every 0.016s ≈ 125°/second continuous rotation.
- `hide me` on TestCylinder removes it permanently on grab (one-time pickup). Change to a temporary hide + show after delay if re-spawn is desired.
- `show text` writes to the `GameText` actor (centre-screen). Ensure `GameText` exists in the scene under UICanvas.
- Name-based fallback auto-attaches each `.events` to its same-named actor — no EventSheet components needed (matches zero-click fallback pattern).
- `when every 0.016 seconds` is ~60Hz. Adjust if frame-rate-dependent speed is needed.
