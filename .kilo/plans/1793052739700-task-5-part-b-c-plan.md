## Open questions / risks

1. **Flax 1.13 animation API names**: The code uses reflection for `AnimationController`, `PlayState`, `States`, `CurrentState`, `Loop`, and animation-ended events. If exact names differ, the editor build will warn (not error — reflection degrades gracefully) and animation won't work until names are matched. The user needs to inspect the Flax console/API in the editor.

2. **Walk animation not exported**: User only has `idle` exported. `loop anim "Walk"` and `play anim "Shoot"` will produce friendly warnings ("unknown anim") until those animations are exported. This is expected — test with `Idle` first, then add walk/shoot when exported.

3. **Anim Graph state naming**: The state name in Flax's Anim Graph must match the Blender Action name exactly, and match what's written in the `.events` file. Case-sensitive.
