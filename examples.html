Event Manager — Worked Examples

v0.1 · Plain-text game logic · Flax Engine · Copy these into .events files

Each example is a complete .events file. Attach it to an actor of the matching name (auto-attach by filename), or point an EventSheet component at it. Words are defined in keywords.html; any missing word here is planned, not shipped.

Actor setup (the one-time editor step)

Place actors in the Flax scene and name them exactly what your events file references. Name matching is case- and space-sensitive.

# In the Flax editor: create these actors and name them exactly:
Player  •  Bullet  •  Enemy  •  SpawnPoint  •  Waypoint  •  Grass  •  Wall
# Then give each one an EventSheet component → Event File (blank = actor's own name):
Player → Player.events  •  Enemy → Enemy.events  •  Wall → Wall.events

No component? A Hero.events file still auto-attaches to an actor named Hero (zero-click fallback).

8-direction top-down movement (Player)

Transform-based movement by default — no colliders needed. Hold shift to run.

# Player.events
when W is held
  move forward speed 5
  loop anim "animation walk"

when S is held
  move back speed 5
  loop anim "animation walk"

when A is held
  move left speed 5
  loop anim "animation walk"

when D is held
  move right speed 5
  loop anim "animation walk"

when Left Shift is held
  move forward speed 10

when W is released
  loop anim "animation idle pose"

Tip: each move writes Position every tick. Tick Use Physics Movement on the EventSheet + put a RigidBody under it to move through physics instead.

Point & click: walk to where you clicked (Ground)

goto there walks to the last clicked position using a baked NavMesh.

# Player.events
when Ground is clicked
  goto there
  loop anim "animation walk"

when me arrives at there
  loop anim "animation idle pose"

Requires a baked NavMesh in the level, and an actor named Ground that receives clicks.

Shooting: spawn a bullet, aim at the nearest enemy (Player)

spawn Bullet at me clones the named scene actor and inherits your facing.

# Player.events
when Left Mouse is pressed
  look at nearest Enemy
  spawn Bullet at me
  play sound "shot.wav"
# Bullet.events — travels forward, dies on hit or after 1s
when me appears
  move forward speed 20

when me touches Enemy
  send message "hit"
  destroy me

when every 1 seconds
  destroy me
# Enemy.events — takes damage, dies at 0
when me appears
  set my health to 3

when message "hit" arrives
  add -1 to my health
  unless my health is higher than 0
    play sound "boom.wav"
    destroy me

Hurt with invulnerability blink (Player)

# Player.events
when me appears
  set my Invulnerable to false

when me overlaps Enemy
  unless my Invulnerable is true
  play sound "hurt.wav"
  add -1 to Lives
  set my Invulnerable to true
  hide me
  wait 1 second
  show me
  set my Invulnerable to false

Weapons & ammo: one held weapon, per-weapon rounds (Player)

A weapon is data, like an enemy type: seventeen <Weapon><Field> globals in WeaponData.events, read before any sheet runs. set weapon to "Shotgun" stores the name in my Weapon, and spawn Bullet then clones that weapon's bullet — once per pellet, fanned across its spread, with its damage, speed, life and knockback stamped on each copy. Ammo lives in my <Weapon>Ammo, and ammo my Weapon means "whatever I am holding", so one fire block serves every gun.

# WeaponData.events — one block per weapon (Pistol, Shotgun, Uzi, Rocket, Grenade, Flamer)
set ShotgunBullet to "ShotgunPellet"
set ShotgunDamage to 6
set ShotgunFireRate to 0.8
set ShotgunSpread to 12  # six pellets fanned over 12 degrees
set ShotgunMultiplier to 6
set ShotgunReload to 2
set ShotgunAmmo to 8
set ShotgunKnockback to 80
set ShotgunLife to 0.8  # short legs — a shotgun, not a rifle
set ShotgunExplosive to false
# Player.events — carry it, spend it, reload it, show it
bind WeaponLabel to my Weapon and my Ammo format "Weapon: {0} Ammo: {1}"

when me appears
  set weapon to "Pistol"
  set ammo Pistol to 25
  set ammo Shotgun to 0

when 2 is pressed
  my HasShotgun is true
  set weapon to "Shotgun"

when Space is pressed
  unless reloading
  unless ammo my Weapon is 0
  spawn Bullet at me offset 30
  add -1 to ammo my Weapon
  play sound "shot"

when R is pressed
  unless reloading
  reload

when reload completes
  print "reload done"

Pickups cannot write another actor's my variables, so the pickup sends a message and the player owns every change: when message "pickup_shotgun" arrives → set my HasShotgun to true → add 8 to ammo Shotgun → set weapon to "Shotgun". Reload time and the magazine size stay in the data file; the sheet only asks.

Audio — menu music, a level switch and dialogue ducking

Menu track fades out, level track fades in

There is one music player: starting a track replaces the old one, and a track started after a fade-out ramps itself back up. Fades are advanced by the event runtime each tick, so no coroutine or animation is involved.

# Menu.events
when scene starts
  loop music "menu"

when PlayButton is clicked
  fade music to 0 in 0.5
  wait 0.5 seconds
  load scene "Level1"
# Level1.events — the music never stopped, only the volume did
when scene starts
  loop music "level1"

when state becomes "boss"
  duck music by 0.6 for 4
  play sound "roar" at Boss

when music ends
  print "the credits track finished"
  loop music "menu"

Volumes are the globals MusicVolume, SoundVolume and MasterVolume (0–1), so a pause menu or settings screen writes them with the same set words and can bind a label to them. play sound "roar" at Boss parents a positional one-shot to that actor; Flax only attenuates a clip imported as a 3D sound.

Fireball hits a wall → wall crumbles + sound

The fireball sends a message; the wall animates and destroys itself. Actions run on me, so the target must run its own logic.

# Fireball.events
when me appears
  move forward speed 30

when me touches Wall
  send message "crash" to Wall
  destroy me

when every 3 seconds
  destroy me
# Wall.events
when message "crash" arrives
  play anim "wall_fall"
  play sound "wall_break.wav"
  destroy me

For physics touches, give both actors colliders and set the manager's Contact Mode to Colliders or Both. Use overlaps (distance-only) if you don't want colliders at all.

Per-actor variables: Hero has health and mana

my … belongs to that actor only — each copy keeps its own. Globals (capitalized) are shared.

# Hero.events — per-actor health / mana
when me appears
  set my health to 100
  set my mana to 100
# Global score / lives (shared by everything)
when game starts
  set Score to 0
  set Lives to 3

Reading anyone's variable: other's damage, Player's gold. Writing: only your own my ….

Items & bag: pick up a sword, equip it, +5 damage

# Sword.events (item actor)
when me gets equipped
  add 5 to my damage
# Player.events — pickup and equip
when me touches Sword
  add Sword to my bag
  play sound "pickup.wav"

when 1 is pressed
  unless my bag has Sword
  equip Sword
# Enemy.events — takes the attacker's damage (possessive read)
when message "damage" arrives
  add -(other's damage) to my health
  unless my health is higher than 0
  destroy me

UI & menus: HUD label and main menu

Menus are just another scene. A label actor named ScoreLabel holds a UIControl with a Label.

# Menu.events (global sheet, title scene)
when scene starts
  set Score to 0
  show PlayButton
  show QuitButton

when PlayButton is clicked
  load scene "Level1"

when QuitButton is clicked
  quit game
# Level1 HUD — keep the label in sync
when scene starts
  show ScoreLabel
  set text of ScoreLabel to Score

when Score changes
  set text of ScoreLabel to Score

Create a GameText actor with a Label for show text "…" center-screen messages.

Animated cursors: the pointer is scene content

There is no cursor importer and no C# to write. A cursor is a UIControl actor named Cursor_<Name>, and the name after the prefix is what the words look up (case-insensitively, so Cursor_Attack answers set cursor "attack").

# Editor setup, once per cursor — this part is not a .events file
1. Under a UI Canvas, add a UIControl actor named Cursor_Attack.
2. Set its UI Control type to Image and give that Image a Brush — the sprite or texture that points. A sprite-atlas slot works: the brush is copied by reference out of the scene, not looked up by asset name.
3. For an animated cursor, add child UI actors under it, each with an Image control. The direct children are the frames, in child order; the parent's own Image is the still frame.
4. Leave them all inactive. The view switches the drawer on only while it draws, and the catalog rescans five times a second, so a brush assigned during play appears within 0.2 s.
# Cursor_Attack.events — the cursor's own sheet
when scene starts
  set my Cursor fps to 12
  set my Cursor hotspot to "4, 4"
  set my Cursor fallback to "cross"

These four variables are actor-local, so they live on the cursor's own sheet. Cursor fps: unset means 12 for a 2+ frame strip, and 0 holds the first frame still. Cursor hotspot: pixels from the pointer to the art's top-left corner — it must be quoted, because a comma inside a bare value is a word break. Cursor fallback: default, hand, cross, no, hidden or image — the OS pointer used when the cursor has no art, so a cursor with no frames never hides the pointer. Cursor image: the file for image, like set my Cursor image to "Content/Cursors/arrow.cur"; Flax loads it through Window.LoadCursorImage (Windows reads .cur/.ani), and a platform that refuses the file keeps the default arrow.

# Game.events — using the cursor (the mode words live with the game logic)
when Q is pressed
  push cursor "Attack"
  aim attack

when aim is done
  pop cursor

when me is hovered
  set cursor "Hand"

when me loses hover
  set cursor to default

hide cursor  /  show cursor  — no pointer and no art, for a cutscene

The pointer comes back by itself when a mode ends, and popping past the bottom keeps default, so a sheet that forgets its pop cannot strand the game on the combat cursor. The automatic sources need no words at all: once a scene authors Cursor_Hand, Cursor_Attack and Cursor_Cross, hovering a unit, hovering a visible enemy and dragging a selection box answer those cursors on their own — set Cursor auto to 0 switches that off, and set Cursor hand to "Point" repoints one rule. Read the answer with my cursor, and react to it with when cursor changes.

A pure OS pointer needs no art at all: name the actor Cursor_Hand, give it no Image, set my Cursor fallback to "hand", and push cursor "Hand" shows the platform hand with nothing drawn or hidden.

Typed enemies: one data table, one gunner sheet (TK4)

An enemy type is six numbers and a name, and they live in data. enemy type "<name>" copies them onto the actor as its own my variables, so a sheet reads my Speed, my SightDistance, my Health, my Weapon, my Hostile and my ExplosionDeath instead of repeating numbers. Adding a type is six more lines in EnemyTypes.events — no C#.

# EnemyTypes.events — the table (one block per type; Zombie and Turret ship too)
set PistolboySpeed to 70
set PistolboySightDistance to 250
set PistolboyHealth to 45
set PistolboyWeapon to "Pistol"
set PistolboyHostile to true
set PistolboyExplosionDeath to false

# and a bystander: no weapon, and `my Hostile false` keeps it out of `when all enemies dead`
set CivilianSpeed to 70
set CivilianWeapon to ""
set CivilianHostile to false
# TK_Gunner.events — one sheet for every armed type; `my name` is the actor's own name
when me appears
  enemy type my name  # actor named "Pistolboy" → the Pistolboy row
  set my mode to "patrol"
  goto random Waypoint speed my Speed

when me sees player by my SightDistance
  my Hostile is true
  set my mode to "chase"
  goto nearest player speed my Speed

when every 0.75 seconds
  my mode is "chase"
  my Armed is true  # set from `my Weapon` in the appear block
  face nearest player
  spawn Bullet at me offset 30  # fires the held weapon — rocket for BazookaBoy

when my Health becomes 0
  add 1 to kills my Type
  if my ExplosionDeath is true
  spawn Explosion at me
  otherwise
  spawn Gib at me offset 0
  destroy me
# Civilian.events — a non-hostile type that bolts when shot
when me appears
  enemy type "Civilian"
  set my FleeSpeed to my Speed + 70
  wander speed my Speed

when message "damage" arrives
  spawn Blood at me
  set my LastDmg to other's damage
  set my Health to my Health - my LastDmg
  face other
  wander speed my FleeSpeed

Setup: EventSheet on the enemy, Event File = TK_Gunner, and name the actor after its type (Flax allows several actors with the same name; a spawned copy like Pistolboy 2 still matches). A name that is not a type warns once and lists the real ones. Types, weapons and every number: EnemyTypes.events and WeaponData.events.

Levels & statistics: clear the room, advance, keep the score

A level is a scene. Every enemy tags itself with my Type, so when all enemies dead fires once when the last one is gone (a non-hostile type is ignored). next level raises when level completes and then loads the next scene at the end of the tick, so the events queued with the signal still run. The run's numbers are ordinary globals — Kills Total, Kills <type>, Shots, Hits, Accuracy, Time Elapsed, LevelName, LevelNumber — so any label can bind one or print one.

# Game.events — the level flow
when level starts
  print "Level started"

when all enemies dead
  show text "Level complete!"
  wait 2
  next level

when level completes
  save stats
# HUD lines and per-level rules
bind KillLabel to kills total format "Kills: {0}"
bind TimeLabel to time elapsed format "Time: {0}s"
bind LevelLabel to level number format "Level {0}"

when every 5 seconds
  kills Zombie is higher than 10
  accuracy is lower than 50
  show text "Sloppy — ammo is not free"

# jumping straight to a level, and the run lifecycle
when F5 is pressed
  set level to 2

when F9 is pressed
  load stats

when F10 is pressed
  wipe game variables
# Enemy.events — the death that feeds all of it
when my Health becomes 0
  add 1 to kills my Type  # counts the type and Kills Total
  spawn Gib at me offset 0
  destroy me

Shots counts a player sheet's spawn Bullet and Hits a landed "damage" on an enemy; Accuracy refreshes once a tick. save stats / load stats are a per-session checkpoint of every global, and wipe game variables forgets them all and re-seeds the level (a new run).

Two players on one keyboard (local co-op / deathmatch)

One sheet drives both players: on a player's sheet when Shoot is pressed means that player's shoot button, and when Left Arrow is held means that player's turn-left key. Key signals carry their owner, so P1's keys never reach P2's sheet. Defaults: P1 = arrows / Space / Left Shift / R / 1-3, P2 = WASD / Left Ctrl / Left Alt / Q / 4-6, and gamepad 0 / 1 raise the same actions.

# Player1.events — the same file runs on Player2 (each actor gets its own `my` variables)
when Shoot is held
  unless reloading
  unless ammo my Weapon is 0
  spawn Bullet at me offset 30
  add -1 to ammo my Weapon

when Sprint is held
  move forward speed 200

when Reload is pressed
  reload

when Weapon 2 is pressed
  set weapon to "Shotgun"
# Game.events — player slots, co-op lives, deathmatch scoring
when player 1 joins
  print "Player 1 joined"

when player 1 dies
  add -1 to Player1 Lives

when player 1 kills player 2
  add 1 to Player1 Kills
  add 1 to Player1 Score

when all players dead
  set state gameover

# an enemy hunting whichever player is closest
bind TargetLabel to my TargetPlayer format "Hunting: {0}"
# Options screen: rebind an action, then keep it
bind P2ShootKey to Player2 ShootKey

when P2Shoot is clicked
  rebind player 2 Shoot

when binding changes
  set text of StatusLabel to my LastBoundKey

when scene starts
  load bindings
  save bindings

Bindings are saved as ordinary globals (Player1 ShootKey, Player2 ShootKey, and so on), so save bindings / load bindings carry them across scenes. Two actors sharing one file is the whole trick: give Player1 and Player2 the same EventSheet and every my variable stays per-actor.

Complete mini-game: Top-Down Shooter

~60 lines total — movement, shooting, enemies, scoring, win/lose. This is the v0.1 acceptance test.

# Game.events (global sheet)
when game starts
  set Score to 0
  set Lives to 3
  show text "Shoot the enemies!"
  wait 2 seconds
  hide text

when every 5 seconds
  unless Score is 5
  spawn Enemy at SpawnPoint

when Score becomes 5
  show text "You win!"
  wait 3 seconds
  restart scene

when Lives becomes 0
  show text "Game Over"
  wait 3 seconds
  restart scene
